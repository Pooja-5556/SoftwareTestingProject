# SoftwareTestingProject
The goal of this testing initiative is to validate the core functionalities of the VWO app through structured manual testing. The project ensures that features such as login, dashboard, account creation, and A/B testing campaigns function as intended across multiple environments and devices.
# 🧪 Manual Testing Project – app.vwo.com

This repository contains the **Test Plan**, **Test Cases**, and other QA documentation for the manual and hybrid testing of [app.vwo.com](https://app.vwo.com) – a platform enabling A/B testing to optimize website conversions.

---

## 📌 Objective

Ensure that all features and functionalities of app.vwo.com perform as expected across various environments, delivering a seamless experience to users optimizing their websites for conversions.

---

## 📚 Scope

### ✅ Features to be Tested
- Login Page  
- Dashboard Page  
- Create Account Page  
- A/B Testing Campaign Creation and Execution

### 🔍 Types of Testing
- Manual Testing  
- Automated Testing  
- Performance Testing  
- Accessibility Testing

### 🌐 Test Environments
- **Operating Systems**: Windows 10, macOS, Linux  
- **Browsers**: Chrome, Firefox, Edge  
- **Devices**: Desktop, Laptop, Tablet, Smartphone  
- **Network**: Wi-Fi, Cellular, Wired  
- **Security**: Passwords, Tokens, Certificates  
- **Roles**: Testers, Developers, Stakeholders
